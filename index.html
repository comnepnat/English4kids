☁️ Sao Lưu & Đồng Bộ Google Drive

💾 Cách 1: Xuất / Nhập File Sao Lưu (Dùng ngay)

Không cần cài đặt

Tải file tiến trình (.json) về lưu thẳng vào thư mục Google Drive trên iPad/máy tính, hoặc khôi phục lại khi đổi thiết bị.

☁️ Cách 2: Đồng Bộ Trực Tiếp Google Drive (1 chạm)

Chưa kết nối

Lưu và tải tự động file english4kids_progress.json trực tiếp trên Google Drive cá nhân của bạn.

Chưa đồng bộ lần nào.
📖 Hướng dẫn tạo Google Client ID miễn phí (chỉ làm 1 lần – 3 phút)
  1. Mở console.cloud.google.com → tạo 1 Project mới (ví dụ English4Kids).
  2. Vào APIs & Services → Library → tìm Google Drive API và bấm Enable.
  3. Vào OAuth consent screen → chọn External → điền tên app → thêm email Google của bạn vào mục Test users.
  4. Vào Credentials → Create Credentials → OAuth client ID → Web application.
  5. Ở mục Authorized JavaScript origins, thêm đúng địa chỉ:
    https://comnepnat.github.io
  6. Bấm Create, sao chép Client ID (đuôi .apps.googleusercontent.com) dán vào ô phía trên và bấm Lưu!
